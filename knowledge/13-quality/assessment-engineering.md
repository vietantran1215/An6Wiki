# Assessment Engineering

## 1. Assessment begins from competency

A good assessment measures a defined capability.

Traceability:

```text
Competency
 → learning objective
 → assessment blueprint
 → question/task
 → evidence
 → mastery decision
```

## 2. Blueprint

Define distribution across:

- competencies;
- cognitive level;
- difficulty;
- question type;
- criticality.

## 3. Question quality

A strong technical question has:

- one intended construct;
- realistic scenario;
- sufficient information;
- plausible distractors;
- defensible answer;
- explanation.

## 4. Cognitive levels

Examples:

- recall;
- explain;
- apply;
- analyze;
- design;
- evaluate.

Senior capability should not be measured only through recall questions.

## 5. Randomized pools

If an assessment draws 30 from 180 questions, the full 180-question bank must still preserve blueprint coverage so any random draw remains representative.

## 6. Critical competencies

Overall score alone can hide dangerous gaps.

Use critical-domain thresholds where necessary.

## 7. Item analysis

After use, inspect:

- difficulty;
- discrimination;
- distractor performance;
- ambiguous feedback;
- time spent.

## Rule

Assessment quality comes from blueprint and evidence validity, not question volume.
