# Instructional Design for Engineers

## Objective

Training should create observable performance, not merely expose learners to slides.

## Preferred sequence

```text
Pain point
 → concept
 → big picture
 → mechanics
 → example
 → implementation
 → experiment
 → assessment
 → reflection
```

## Learning objectives

Good objectives use observable verbs:

- implement;
- diagnose;
- compare;
- design;
- evaluate;
- defend.

Weak:

> Understand RAG.

Better:

> Implement hybrid retrieval and demonstrate through Recall@K evaluation when it outperforms dense-only retrieval.

## Lab structure

A reproducible lab includes:

- prerequisites;
- setup;
- target outcome;
- steps;
- code;
- expected output;
- failure/debug section;
- extension challenge.

## Progressive scaffolding

Move through:

1. worked example;
2. guided modification;
3. partial implementation;
4. independent task;
5. capstone.

## Rule

A learner should finish with evidence of capability, not only notes.
