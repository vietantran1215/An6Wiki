# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture Decision Record. |
| Agent | Runtime-controlled AI component that can choose actions from state and observations. |
| Agentic RAG | RAG with dynamic routing, retrieval, grading, rewriting, or iteration. |
| AST | Abstract Syntax Tree. |
| Backpressure | Mechanism preventing producers from overwhelming slower consumers. |
| BM25 | Lexical retrieval algorithm based on term matching and document statistics. |
| Circuit Breaker | Resilience pattern that temporarily blocks calls to a failing dependency. |
| CI/CD | Continuous Integration / Continuous Delivery or Deployment. |
| Context Builder | Component that assembles approved evidence before model invocation. |
| Corrective RAG | RAG that checks retrieval quality and corrects weak evidence paths. |
| DLQ | Dead-Letter Queue. |
| DLP | Data Loss Prevention. |
| E2E | End-to-End. |
| Eventual Consistency | Model where distributed state converges over time. |
| Golden Dataset | Curated benchmark dataset used for evaluation/regression. |
| GraphRAG | Retrieval using graph-structured knowledge or graph traversal. |
| HITL | Human in the Loop. |
| Hybrid Retrieval | Combination of lexical and semantic retrieval. |
| HyDE | Hypothetical Document Embeddings. |
| IAM | Identity and Access Management. |
| Idempotency | Repeating an operation does not create unintended extra effects. |
| IaC | Infrastructure as Code. |
| LangGraph | Graph framework for stateful LLM/agent workflows. |
| LLM Gateway | Controlled entry point for model routing and policy enforcement. |
| MCP | Model Context Protocol. |
| MMR | Maximal Marginal Relevance. |
| Modular Monolith | Single deployable application with strong internal module boundaries. |
| Multimodal RAG | RAG over multiple modalities such as text and images. |
| Observability | Understanding system behavior via logs, metrics, traces, and domain signals. |
| OpenTelemetry | Vendor-neutral telemetry standard. |
| Outbox Pattern | Reliable event-publication pattern using the same DB transaction as business state. |
| RAG | Retrieval-Augmented Generation. |
| RAGAS | RAG evaluation framework. |
| RBAC | Role-Based Access Control. |
| Reranker | Component that reorders retrieval candidates with a stronger relevance model. |
| RRF | Reciprocal Rank Fusion. |
| Saga | Distributed workflow of local transactions and compensations. |
| SLI | Service Level Indicator. |
| SLO | Service Level Objective. |
| SRE | Site Reliability Engineering. |
| Tool Calling | Model-driven invocation of typed external operations. |
| Vector Database | Store/index optimized for vector similarity search. |
| Vectorless RAG | Retrieval architecture that does not depend on dense vectors as the primary mechanism. |
