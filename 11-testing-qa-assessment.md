# Testing, QA & Assessment Engineering

## 1. Quality is broader than test execution

Modern QA covers requirements, design risks, unit/integration/API/E2E testing, security, performance, observability, release risk, AI evaluation, and production feedback.

## 2. AI-native QA

Capabilities include AI-assisted requirement analysis, test design, test-data engineering, automation modernization, defect intelligence, RAG/LLM evaluation, red teaming, governance, release gates, and agentic QA.

## 3. AI-system testing

Probabilistic systems need golden datasets, rubrics, regression suites, adversarial tests, drift monitoring, evaluation dashboards, risk registers, and human-review criteria.

## 4. Assessment engineering

A serious assessment needs competency/LO mapping, blueprint, cognitive-level distribution, realistic scenarios, plausible distractors, critical-domain thresholds, SME review, versioning, randomized pools, and post-use item analysis.

## 5. Evidence model

```text
Knowledge → Practice → Evidence
```

Evidence can be code, an architecture decision, test specification, evaluation report, incident analysis, or technical defense.

## 6. Quality gates

Combine deterministic tests, security checks, performance thresholds, AI regression evaluation, and human review for high-risk behavior.
